# My IT Career Tracker

Phone/laptop Progressive Web App for the 48-week Cloud → DevOps → AI/MLOps roadmap.

## Put it online
Upload all files to a GitHub repository and enable GitHub Pages. Open the HTTPS Pages address on your phone and laptop.

## iPhone
Open the site in Safari → Share → Add to Home Screen → Add.

## Laptop
Open the site in Chrome/Edge. Use the browser's Install App option if offered.

## Important
Progress is stored with localStorage, so phone and laptop do not sync yet. A later version can add Firebase or Supabase login/cloud sync.
